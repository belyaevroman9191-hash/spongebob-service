# SPONGEBOB SERVICE + ADMIN

## Запуск

```bash
npm start
```

Сайт: `http://localhost:3000/`
Админка: `http://localhost:3000/admin`

## Доступ к админке

Доступ жёстко ограничен двумя Telegram-никами:

- `@GSMSHEIKHO9` — главный администратор
- `@SuportSpongeBob` — администратор с полным доступом

Третьего пользователя создать через сайт нельзя. Первый запуск/регистрация отключены.

Главный администратор может менять настройки сайта и очищать аналитику. Администратор имеет доступ к дэшборду, посетителям, активности и экспорту, но не к настройкам/очистке.

## Аналитика

Сохраняются:

- просмотры страниц;
- уникальные посетители;
- активные посетители за последние 2 минуты;
- клики по каждому каналу;
- источник перехода;
- устройство/browser user-agent;
- Telegram username/name, если сайт открыт внутри Telegram WebApp и Telegram передал эти данные;
- журнал событий.

Данные сохраняются в `data/db.json` после запуска.

## Важно про Telegram

Обычная ссылка из Telegram сама по себе не передаёт сайту username пользователя. Telegram username можно получить автоматически, когда сайт запущен как Telegram WebApp с корректной интеграцией Telegram.
